# Data Model: R0 Agent Fleet Control Plane Walking Skeleton

## Conventions

- Primary keys are UUIDs generated by ADLC.
- All timestamps are UTC with timezone.
- Every workspace-owned row includes `workspace_id`, either directly or through a required parent.
- Secret values are encrypted through the Observability and Governance encryption boundary and are never present in ordinary configuration JSON.
- JSON snapshots are immutable, schema-versioned, and redacted before persistence.
- Audit and raw-event records are append-only.
- Cross-module writes use application-service ports; shared database access does not grant write ownership.

## Enumerations

### Capability Status

`pending_validation | valid | invalid | unreachable`

### Agent Status

`draft | published`

### Session Status

Nonterminal: `creating | provisioning | running`

Terminal: `completed | failed | canceled | interrupted`

### Executor Status

`not_requested | requested | connecting | connected | stopped | failed`

### Artifact Status

`valid | missing | unreadable | outside_workspace | invalid_type`

### Connector Status

`offline | online | degraded`

## State Transitions

### Agent

```text
draft --publish succeeds--> published
published --edit--> published agent + new draft version
new draft --publish succeeds--> old version superseded + new version published
```

Publish failure leaves the draft unchanged and appends error/audit evidence.

### Session

```text
creating -> provisioning -> running -> completed
    |             |            |------> failed
    |             |            |------> canceled
    |             |            `------> interrupted
    |             |-------------------> failed/canceled/interrupted
    `---------------------------------> failed/canceled
```

- A terminal state is immutable.
- User cancellation produces `canceled` even if the upstream cancel acknowledgement arrives later; late events remain evidence but cannot change the terminal state.
- Confirmed executor or stream loss without a reported terminal outcome produces `interrupted`.
- External execution errors produce `failed`.

### Capability

```text
pending_validation -> valid
pending_validation -> invalid
valid -> unreachable
invalid/unreachable -> pending_validation -> valid|invalid|unreachable
```

Agent publication and session start require every required capability to be `valid` at the respective readiness check.

## Snapshot Shape

Each `effective_config_snapshot_json` contains:

- `schema_version`
- workspace ID, type, approved workspace-relative settings, and connector version
- agent ID, immutable version ID, model, instructions hash, and approval mode
- skill ID, source reference, resolved version, compatibility, and capability directories
- MCP ID, label, URL origin/host summary, allowed tools, required flag, and credential fingerprint only
- OpenAI request options after redaction
- snapshot creation time

It never contains API keys, executor keys, MCP tokens/headers, encrypted ciphertext, or environment remote URLs.

## Required Indexes

- Active sessions by `(workspace_id, status, last_event_at desc)`.
- Session history by `(workspace_id, created_at desc)`.
- Raw and normalized events by `(session_id, sequence_number)`.
- Audit history by `(workspace_id, entity_type, entity_id, created_at desc)`.
- Artifacts by `(session_id, report_sequence)` and `(workspace_id, reported_at desc)`.
- Capability validation lists by `(workspace_id, status, updated_at desc)`.
